This directory is used to store extra data.

 - the injected CUDA source code is generated and stored here. CuPy loads these kernels.
 - the ./ptx directory is generated by the ./build.sh script of this git repository. Although the PTX code will be generated on-the-fly anyway, it is better to include the ptx code to ensure compatibility with a minimum CUDA version corresponding to the version of cuda-bindings and cuda-toolkit in the uv lock file.
